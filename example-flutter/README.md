# Provisioner Jatt Flutter example

Same host flows as the Kotlin `example` module: single mode, single-mode automation, account FRP, organization name, and the provisioning screen with QR, pairing code, automation, and the device lists.

It depends on `com.beastblocks:provisioner-jatt:1.3.0` from the local `repo/` directory.

```bash
flutter run
```
